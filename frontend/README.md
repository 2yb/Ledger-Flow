# Ledger Flow

### A modern full-stack ledger and transaction management system

Manage accounts, track credits and debits, and maintain reliable account balances through a clean React interface and a TypeScript REST API.

![React](https://img.shields.io/badge/React-2026-61DAFB?logo=react&logoColor=black)
![TypeScript](https://img.shields.io/badge/TypeScript-Strict-3178C6?logo=typescript&logoColor=white)
![Node.js](https://img.shields.io/badge/Node.js-Backend-339933?logo=nodedotjs&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-Database-4169E1?logo=postgresql&logoColor=white)

## Highlights

- Account creation and account management
- Credit and debit transactions
- Balance validation and insufficient-funds protection
- Duplicate transaction reference validation
- Paginated transaction history

## Architecture

React + TypeScript → Express REST API → Service Layer → PostgreSQL
